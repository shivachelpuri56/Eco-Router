♾ Responsible AI

How Eco-Router uses AI responsibly — with human oversight and clear limitations.
🚫
AI Does Not Control Routing
All routing decisions are made by the deterministic carbon-aware engine. The AI cannot override health checks, select regions, or modify infrastructure state.
🔎
Grounded in Telemetry
AI responses use only supplied Eco-Router telemetry and curated knowledge documents. AI does not access the internet or fabricate metrics.
📊
Forecasts Are Labelled Predictions
All forecast values are explicitly labelled FORECAST — PREDICTED, NOT MEASURED. Insufficient data results in a clear INSUFFICIENT DATA message, not fabricated values.
👤
Human Oversight Preserved
AI recommendations are advisory only. Engineers can override routing policy via configuration. No automated infrastructure changes are triggered by AI output.
🔒
No API Keys Exposed
API keys (Gemini, Electricity Maps) are never included in HTML, JavaScript, or browser responses. Missing keys trigger AI DEMO MODE gracefully.
🔢
ESTIMATED Savings Only
All carbon saving figures are estimates derived from simulated data and configurable assumptions. The platform explicitly avoids claiming verified real-world emission reductions.
🎤
Voice Data Not Stored
Voice recognition uses the browser's native Web Speech API. Audio is processed locally by the browser — only the transcribed text is sent to the backend AI endpoint.
📈
Mock Data Clearly Labelled
All simulated carbon intensity values are labelled SIMULATED GRID DATA. Data source (mock/live/cached/stale) is always shown in the UI and API responses.
